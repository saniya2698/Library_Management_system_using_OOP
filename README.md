# 📚 Library Management System

## 📖 Overview

The **Library Management System** is a console-based Python application developed using **Object-Oriented Programming (OOP)** concepts. It helps manage library books through a simple menu-driven interface. Users can add, view, search, issue, return, and delete books efficiently.

This project demonstrates the implementation of **classes, objects, methods, and encapsulation** while solving a real-world problem.

---

## ✨ Features

* ➕ Add New Book
* 📚 View All Books
* 🔍 Search Book by Book ID
* 📖 Issue Book
* ↩️ Return Book
* 🗑️ Delete Book
* 📋 Menu-Driven Interface
* ❌ Invalid Choice Handling

1. Clone the repository:

   ```bash

   ```

2. Navigate to the project folder:

   ```bash
   cd Library-Management-System
   ```

3. Run the program:

   ```bash
   python library_management.py
   ```
